# Представляем вашему вниманию бенчмарк для оценки ответов больших языковых моделей в домене российского права.

### Бенчмарк создан на вычислительный грант от [Yandex OpenSource](https://opensource.yandex/grants/)

## Бенчмарк основан на анонимизированных решениях судов в следующих отраслях:

- **Административное право**  
- **Конституционное право**  
- **Экологическое право**  
- **Финансовое право**  
- **Гражданское право**  
- **Семейное право**  
- **Право социального обеспечения**  
- **Трудовое право**  
- **Уголовное право**  
- **Жилищное право**  

### Для каждой отрасли права мы выбрали по 100 судебных решений.

---

## Для проверки способности моделей генерировать ответы мы используем семь разделов в каждом судебном решении:

1. **Требования истца**  
2. **Аргументы истца**  
3. **Аргументы ответчика**  
4. **Оценка судом представленных сторонами доказательств**  
5. **Логические шаги в рассуждениях судьи и промежуточные выводы**  
6. **Применимые в судебном деле нормы права**  
7. **Решение суда**  

---

## Каждому из разделов соответствуют следующие инструкции:

1. *"На основе вводных данных определите требования истца по рассматриваемому делу."*  
2. *"На основе вводных данных определите аргументы истца по рассматриваемому делу."*  
3. *"На основе вводных данных определите аргументы ответчика по рассматриваемому делу."*  
4. *"На основе вводных данных определите оценку судом представленных сторонами доказательств по рассматриваемому делу."*  
5. *"На основе вводных данных определите логику рассуждений судьи по рассматриваемому делу."*  
6. *"На основе вводных данных определите применимые нормы права по рассматриваемому делу."*  
7. *"На основе вводных данных определите краткое содержание окончательного решения судьи по рассматриваемому делу."*  

---

### При этом:  
- **Правильный ответ** включает соответствующий инструкции пункт.  
- **Вводные данные** включают все остальные пункты.
