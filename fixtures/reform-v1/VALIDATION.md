# Проверка reform fixture v0.1.0

Дата: 2026-10-02. Область: design artifact NL-107, все 16 завершённых входов D16.

## Воспроизведение

Из корня проекта:

```sh
python3 fixtures/reform-v1/check_fixture.py
```

Checker читает fixture.json, проверяет соответствие конечному domain, именованные source bindings, таблицу в README и рассчитывает последствия по положениям design artifact с точной рациональной арифметикой.

## Результаты

| Проверка                          | Результат                                                                     |
| --------------------------------- | ----------------------------------------------------------------------------- |
| Полнота и отсутствие повторов D16 | 16 из 16 комбинаций                                                           |
| Таблица ожидаемых значений        | 48 вычислений: 16 случаев × 3 модели                                          |
| Source bindings                   | 17 положений имеют существующие именованные источники                         |
| Q-AB-equivalence                  | Последствия совпадают в 16 случаях                                            |
| Q-AC-no-increase                  | Срок не увеличивается; другие компоненты сохранены в 16 случаях               |
| Q-AC-strict-M                     | Строгое уменьшение в 8 случаях с установленным M                              |
| Q-AC-outside-M                    | Полное сохранение последствий в 8 случаях с опровергнутым M                   |
| Q-M-monotonicity                  | Строгое уменьшение и сохранение других компонентов в 24 парах: по 8 на модель |
| C-missing-exclusion               | Два counterexamples к Q-AC-outside-M                                          |
| Дробные сроки                     | Не возникли в D16; округление не использовалось                               |

Первый counterexample: `K1-011`, то есть K1, M=false, N=true, E=true. A: 120 месяцев и 200 000 DEMO; ошибочный вариант: 90 месяцев и 200 000 DEMO. Второй — аналогичное сочетание K2: 240 → 180 месяцев при штрафе 400 000 DEMO.

Дополнительно на временных копиях проверено отклонение трёх повреждений: изменение ожидаемого срока в первой строке, удаление одной комбинации D16 и подмена source binding базового положения. Все три вызвали отказ аудита; оригинальный fixture сохранён.

## Область свидетельства

Результат — **arithmetic-audited**. В этом audit script есть собственное процедурное вычисление design artifact; его результаты сравниваются с явно зафиксированной таблицей. Source binding проверяет наличие и адрес источника, а соответствие смысла естественного текста требует отдельного review.

Это не независимое отношение допустимости, Lean proof, подписанная comparison receipt или проверка приложения. Существующее приложение пока поддерживает только M0. Критерии completion и условные ветви нового профиля здесь специфицированы; runtime-проверка остаётся следующей работой.
