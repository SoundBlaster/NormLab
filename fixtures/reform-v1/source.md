# Синтетический фрагмент: общие правила смягчения

Версия: `0.1.0`. Автор: NormLab synthetic laboratory. Назначение: NL-107.

Все положения ниже придуманы для эксперимента. Они не являются формализацией действующего законодательства. Статус — спецификация fixture; подключение к приложению и формальная проверка находятся в следующих задачах.

## Область и определения

Исследуется один субъект и один текущий эпизод. Принадлежность к группе `K1` или `K2` задана входом. Основания ответственности и выбор группы находятся вне scope этого фрагмента.

- **M — возмещение:** полностью возмещён синтетический имущественный ущерб.
- **N — самостоятельное сообщение:** субъект сам сообщил о синтетическом нарушении.
- **E — повторность:** установлена повторность синтетического нарушения. Это контекст текущего эпизода; история предыдущих эпизодов здесь не моделируется.

Каждое обстоятельство устанавливает simulated reviewer с мотивировкой. Для завершённого случая M, N и E имеют значения `established` или `refuted`. Все восемь сочетаний этих трёх значений допустимы в каждой группе.

Результат содержит синтетическую квалификацию группы, срок в целых месяцах и штраф в единицах `DEMO`. Иные последствия не входят в scope. Штраф сохраняется при всех преобразованиях срока.

## Порядок применения

1. Выбрать ровно одно базовое последствие по группе.
2. Определить действие исключения E для правила N.
3. При M уменьшить текущий срок по правилу M ровно один раз.
4. При N, если его правило не исключено, уменьшить полученный срок на четверть ровно один раз.

Оба уменьшения обязательны. Они последовательно умножают срок; доли уменьшений не складываются относительно исходной базы. У всех допустимых входов получается целое число месяцев, поэтому округление не выполняется. Дробный результат за пределами этого fixture должен быть отклонён как неподдержанный.

В ledger учитываются все положения выбранной модели, включая положения другой группы. Для них используется `inapplicable` с основанием несовпадения группы. Исключение имеет `applied`, только когда одновременно установлены N и E. При этом правило N получает `excluded`, а не `inapplicable`. Если N опровергнуто, правило N и исключение имеют `inapplicable` независимо от E.

## Модель A: исходная, с повторениями

### A-BASE-K1

Для группы K1 базовое последствие: квалификация K1, 120 месяцев, штраф 200 000 DEMO.

### A-BASE-K2

Для группы K2 базовое последствие: квалификация K2, 240 месяцев, штраф 400 000 DEMO.

### A-M-K1

Для группы K1 при установленном M срок обязательно сокращается на треть: текущий срок умножается на `2/3`. Штраф не изменяется.

### A-M-K2

Для группы K2 при установленном M срок обязательно сокращается на треть: текущий срок умножается на `2/3`. Штраф не изменяется.

### A-N-K1

Для группы K1 при установленном N срок обязательно сокращается на четверть: текущий срок умножается на `3/4`. Штраф не изменяется. Исключение A-X имеет приоритет перед этим уменьшением.

### A-N-K2

Для группы K2 при установленном N срок обязательно сокращается на четверть: текущий срок умножается на `3/4`. Штраф не изменяется. Исключение A-X имеет приоритет перед этим уменьшением.

### A-X

При установленном E уменьшение по N исключается для обеих групп. Уменьшение по M сохраняет обязательность. Исключение не создаёт самостоятельного увеличения базового срока.

## Модель B: общие правила, сохранение последствий

### B-BASE-K1

Для группы K1 базовое последствие: квалификация K1, 120 месяцев, штраф 200 000 DEMO.

### B-BASE-K2

Для группы K2 базовое последствие: квалификация K2, 240 месяцев, штраф 400 000 DEMO.

### B-M

Для обеих групп при установленном M текущий срок обязательно умножается на `2/3`. Штраф не изменяется. Это общее правило заменяет A-M-K1 и A-M-K2.

### B-N

Для обеих групп при установленном N текущий срок обязательно умножается на `3/4`. Штраф не изменяется. Исключение B-X имеет приоритет. Это общее правило заменяет A-N-K1 и A-N-K2.

### B-X

При установленном E уменьшение по N исключается для обеих групп. Уменьшение по M сохраняет обязательность. Смысл A-X сохранён.

## Модель C: усиление общего смягчения M

### C-BASE-K1

Базовое последствие группы K1 сохраняется: квалификация K1, 120 месяцев, штраф 200 000 DEMO.

### C-BASE-K2

Базовое последствие группы K2 сохраняется: квалификация K2, 240 месяцев, штраф 400 000 DEMO.

### C-M

Для обеих групп при установленном M текущий срок обязательно умножается на `1/2`. Штраф не изменяется. Это единственное намеренное изменение нормативного смысла относительно B.

### C-N

Для обеих групп при установленном N текущий срок обязательно умножается на `3/4`. Штраф не изменяется. Исключение C-X имеет приоритет. Смысл B-N сохранён.

### C-X

При установленном E уменьшение по N исключается для обеих групп. Уменьшение по M сохраняет обязательность. Смысл B-X сохранён.

## Учебный ошибочный вариант

`C-missing-exclusion` повторяет C, но теряет положение C-X. Он не входит в основной набор A/B/C и используется для проверки обнаружения непредусмотренного изменения.

Заявление «при опровергнутом M последствия сохраняются относительно A» для него неверно. Свидетель: K1, M опровергнуто, N установлено, E установлено. В A получается 120 месяцев, в ошибочном варианте — 90 месяцев. Штраф в обоих случаях равен 200 000 DEMO.
