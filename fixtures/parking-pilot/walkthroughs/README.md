# Пять повседневных сценариев парковочного прототипа

Задача [#193](https://github.com/SoundBlaster/NormLab/issues/193), 22.10.2026.
Машиночитаемые планы: [cases.json](cases.json). Основания нормы:
[source pack](../../../docs/sources/moscow-parking/2026-10-22/README.md).

Фактический HTTP/Lean-прогон этих планов сохранён отдельно:
[Parking Lean PoC](../../../docs/PARKING_LEAN_POC.md). Поле `observed=false`
ниже сохраняет статус исходных ожиданий, а не отменяет последующий отчёт.

## Что это показывает

Проверяем подход на одной статье: **текст → подтверждение утверждений →
отдельные юридические обстоятельства → draft-расчёт → исправление и пересчёт**.
Сюжеты синтетические, имена и зоны учебные. Это планы прохождения,
а не результаты inference, browser-тестов, expert gold или оценка accuracy.
`expectedDraft` описывает ожидаемое поведение текущего evaluator по коду;
`observed=false` явно оставляет проверку в интерфейсе следующей задачей.

## Как пройти один сценарий

1. Создать отдельный черновик, вставить фабулу, получить разбор или добавить
   утверждения вручную. Все утверждения сначала proposals; не подтверждать их
   только потому, что они есть в этом файле.
2. Проверить цитаты, участников, ТС, эпизод, отрицания и противоположные сообщения.
   Если модель пропустила нужное, внести вручную. Подтверждение разметки ещё
   не подтверждает юридические обстоятельства.
3. В юридическом разделе указать координаты и принять **отдельное** решение по
   каждому условию. Таблицы ниже — учебные ответы человека для воспроизведения,
   не допустимые автоматические defaults. Дополнения, которых нет в фабуле,
   нельзя выдавать за цитаты или факты, извлечённые LLM.
4. Сохранить и нажать расчёт. Проверить status, основания, пробелы/конфликт,
   наличие кандидата и сравнение названной суммы. Все ожидаемые результаты
   имеют `liability=not-assessed`, `proof=none`, нормативный статус research-draft.
5. Выполнить описанное уточнение. При редактировании разметки снова завершить
   её review; затем обновить юридические решения и явно пересчитать. Предыдущая
   ревизия остаётся в истории, её вывод не относится к изменённым входам.

JSON — **не HTTP request**: UUID черновика/ревизии/утверждений и request ID не
придуманы заранее. `runtimeManifestSHA256` — hash байтов manifest для фиксации
исследуемого кода, не runtime `packageDigest`; последний берётся из API.
Для поправки применяются только указанные `findingChanges` по condition ID и
`coordinateChanges` по ключу; прочие решения сохраняются.

`fragment-matched` означает совпадение условий узкого фрагмента, а не «штраф
законен». `fragment-refuted` опровергает условие этого фрагмента, а не все
возможные нарушения. `unsupported` — честная граница модели, не отказ человеку
и не доказательство наличия/отсутствия ответственности.

## W01 — Забыл оплатить

> 1 октября 2026 года с 10:00 до 10:40 я, Алексей, оставил свой личный легковой автомобиль на платной городской уличной парковке в Москве, в учебной зоне М-101. Забыл оплатить: сессию так и не запустил. В письме указали штраф 3 000 рублей.

### Что нельзя потерять в тексте

- личный легковой автомобиль
- с 10:00 до 10:40
- в Москве, в учебной зоне М-101
- Забыл оплатить: сессию так и не запустил.
- В письме указали штраф 3 000 рублей.

- Отвечает ли место понятию городской парковки и был ли весь интервал платным?

## W03 — Не помню, оплатил ли

> Припарковался в платной зоне Москвы. Не помню, оплатил ли.

### Что нельзя потерять в тексте
