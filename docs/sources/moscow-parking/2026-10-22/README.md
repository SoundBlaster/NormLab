# Источники парковочного прототипа

Срез: **22.10.2026**, задача [#193](https://github.com/SoundBlaster/NormLab/issues/193).
Пилотная норма — **ч. 2 ст. 8.14 КоАП города Москвы**, Закон Москвы от
21.11.2007 № 45. Это региональный кодекс; общие положения федерального КоАП РФ
остаются отдельной зависимостью.

## Зачем этот пакет

Сохранить проверяемые основания для одной демонстрации:
**текст → решения человека → условия нормы → объяснённый draft-результат**.
Пять сценариев находятся в [walkthroughs](../../../../fixtures/parking-pilot/walkthroughs/README.md).

Это архив исследовательских источников, а не новый исполняемый `NormPackage`.
[Runtime manifest](../../../../norms/moscow-parking/manifest.json) и его история
не меняются. Флаги остаются `currentLawVerified=false`,
`liabilityModelComplete=false`, `proof=none`. Чтение фрагмента агентом не заменяет
юридический semantic review.

## Что сохранено

[manifest.json](manifest.json) содержит URL запроса и ответа, UTC retrieval time,
HTTP status, media type, размер и отдельные SHA-256 для originals и text.
Суммарно исходные документы занимают около 17,5 MB. PDF сохранены целиком,
без пересжатия и вырезания страниц. HTML — полученные байты ответа, без
выполнения скриптов; для чтения используйте текстовую копию.
`.gitattributes` сохраняет line endings архивных файлов; исходный whitespace
в извлечении PDF оставлен как evidence, без автоформатирования.

PDF с text layer извлечены `pypdf 6.10.0` с сохранением порядка текста.
Для сканов S04/S12 сделана ручная транскрипция выбранных положений по
отрендеренным страницам; пробелы/переносы и маркеры списка нормализованы,
OCR не применялся. Это не полный текст приложений. Метод записан у каждого
файла, оригинал остаётся авторитетным при расхождении транскрипции.

У каждого fragment есть locator, quote и `[start, end)` в соответствующей
text-копии, в Unicode code points. Это диапазон **сохранённого извлечения**,
не координаты символов внутри PDF/HTML и не подпись издателя.
SHA-256 фиксирует байты, но не доказывает полноту, актуальность или юридическую
правильность интерпретации.

Эпизод, ТС, участник, дата, место и интервал — координаты воспроизводимого
разбора. Их обязательность в UI — контракт прототипа, не утверждение о составе
процессуального документа. Названная в фабуле сумма — отдельное утверждение,
сравниваемое с кандидатом, а не вход для выбора размера санкции.

## Граница завершённости

При подготовке визуально сверены восемь страниц: S01 — PDF с. 50;
S02 — с. 6 и 65; S04 — с. 8–10; S12 — с. 1–2. Проверены SHA-256 и размеры
шести originals и шести text-копий, все 12 диапазонов цитат, локальные ссылки,
структура пяти планов и неизменность байтов runtime manifest относительно
`d52c71fa13b0b6afcdac7ca79dfc26b22c58f82d`. Prettier прошёл для изменённых
Markdown/JSON. Это artifact checks; tests, inference, UI-прогон и deploy
в этой задаче не выполнялись.

Для демонстрации подготовлены источники и планы человеческих решений.
Три вопроса остаются открытыми до нормативного lock:

1. Применимая на дату события редакция ст. 8.14, первичные публикации и
   последующие изменения.
2. Действующая цепочка правил обычной оплаты и основание платности конкретного
   места/интервала. S12 разрешает один прежний вопрос о месячном лимите,
   но не заменяет проверку всех изменений S03/S06.
3. Общая часть КоАП РФ и отнесение ответственности, включая автоматическую
   фиксацию. Полной квалификации и Lean certificate пока нет.

Полная модель корректировок, льгот, специальных тарифов, публичный консультант
и универсальная библиотека источников не входят в этот результат.

Следующий ход — пройти пять сценариев в UI, проверить понятность результата и
исправления человеком, затем подключить к результату раскрытие этих оснований.
