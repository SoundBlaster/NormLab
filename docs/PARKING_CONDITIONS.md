Дата: 2026-10-04. Основание: [реестр источников](PARKING_SOURCES.md). Статус: design draft для corpus и review; исполняемые правила ещё не утверждены.

## Предлагаемая последовательность решения

1. Проверить границы сценария и нормативного пакета: эпизод, территория, вид парковки, субъект и дата.
2. Установить наличие обязанности оплаты с учётом режима и применимых исключений.
3. Рассмотреть платёж, временные условия, выезд и допустимые исправления по зафиксированной редакции.
4. Отдельно проверить основания отнесения события к субъекту и материальные условия ответственности.
5. Вычислить последствия в поддержанном scope; затем сверить исходное утверждение о санкции.

Это инженерная декомпозиция, а не утверждение, что эти пять шагов исчерпывают действующее право. Нельзя реализовать `paid_zone && !paid => guilty`. До закрытия C08/C16 допускается только вывод о проверенных условиях обязанности/неуплаты с явной границей, а не надпись «состав доказан».

## Типы выводов для будущего UI

| Вывод                                     | Значение                                                                                                  |
| ----------------------------------------- | --------------------------------------------------------------------------------------------------------- |
| Условия поддержанного фрагмента выполнены | Все включённые predicates установлены; показываются assumptions и границы проверки ответственности        |
| Условие выбранного фрагмента опровергнуто | Назван конкретный predicate; это не означает отсутствия любых иных нарушений                              |
| Требуется уточнение                       | Существенный вход неизвестен; показать вопрос и возможные исходы                                          |
| Противоречие                              | Есть несовместимые reviewed assertions; показать источники, не выбирать скрытно                           |
| Не поддержано                             | Не хватает семантики или нормативной зависимости; пользовательское подтверждение не устраняет этот пробел |
| Условный результат                        | Расчёт на явно гипотетической предпосылке; не меняет факты основного эпизода                              |

Числовой baseline санкции для граждан в S01 — 5 000 рублей. Его использование требует lock применимой редакции и остальных условий. Не подставлять сумму в `inconclusive` как уже назначенное наказание.

## Seeds для corpus

Это сценарии для подготовки эталонов, не выполненные tests и не окончательные правовые выводы. Во всех случаях AI должен извлекать только написанное, а review отдельно устанавливает недостающие входы.

| Case | Отличие фабулы                                                                                  | Что должен выявить конвейер                                                                    |
| ---- | ----------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------- |
| P01  | Обычная городская парковка; подтверждён платный период; оплаты нет; исключения явно рассмотрены | Кандидат положительного нормативного случая после закрытия общих зависимостей                  |
| P02  | Успешная своевременная оплата правильного автомобиля/зоны и всего интервала                     | Отличить оплату от P01; не выводить неоплату лишь из упоминания штрафа                         |
| P03  | Указано только «оставил машину в платной зоне»                                                  | Уточнить место, время, платёж и исключения; не додумать неуплату                               |
| P04  | «Оплатил», но другой номер или зона; позже исправлено                                           | Выделить исходный платёж и correction; актуальная правовая ветвь пока Open                     |
| P05  | Платёж на границе пяти минут; время описано приблизительно                                      | Не округлять неизвестность до нарушения; запросить точность/исследовать ветвь                  |
| P06  | Воскресенье: обычный и повышенный тариф в двух эпизодах                                         | Выбор эпизода; не применять глобальное правило бесплатного воскресенья                         |
| P07  | Резидент; разрешение неизвестно / территория другая / ночной или дневной период                 | Разложить разрешение и время; не признать льготу по месту проживания                           |
| P08  | Инвалид на обычном месте либо на специальном; условия реестра/знака не указаны                  | Показать конкретные пробелы; не смешать льготу с другим нарушением                             |
| P09  | Неоплата и оплата одновременно утверждаются для одного интервала                                | Сохранить конфликт и source spans; никакого автоматического выбора                             |
| P10  | Автомобиль организации, частная площадка либо парковка со шлагбаумом                            | Явный unsupported/outside scope; сохранить неподдержанные обстоятельства                       |
| P11  | Заявлен штраф 3 000 / 5 000 рублей за тот же выбранный эпизод                                   | Извлечь proposal; сверить с зафиксированным расчётом, не использовать сумму как факт нарушения |
| P12  | Сбой приложения, вынужденная остановка или автоматическая фиксация чужого автомобиля            | Показать зависимость ответственности и исключений; не вынести безусловный verdict              |
