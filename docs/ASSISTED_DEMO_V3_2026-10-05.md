# Локальный assisted demo: v3 и ручная проверка

## Критерий

Для локального демо согласована цель **50% кейсов без критических ошибок до ручной правки** и обязательная возможность исправить разметку. 80% остаётся дальнейшей целью. Достижение 50% ещё не установлено: прежние 28/40 selected semantic probes проверяют отдельные утверждения, а не весь critical-error-free case.

## Изменение

HTTP extractor вызывает `evaluation/two_stage_v3.py` без discovery replay: два свежих model calls, discovery v2 и classification v3. Сервер проверяет pipeline identifier, source digest и точное совпадение цитат; принимает только model/pending statements. Исходный ответ сохраняется отдельно от ручных изменений. При ошибке извлечения прежняя ревизия сохраняется.

Начальный subject нового ручного утверждения исправлен с episode_1 на vehicle_1. Это редактируемый идентификатор, требующий проверки привязки к фабуле.

## Проверка в Browser Preview

Проверен один synthetic текст: «Я оплатил парковку. В письме написано: я не оплатил парковку.» Использованы Codex In-app Browser через Computer Use и локальный GPT OSS 20B в LM Studio. Создан отдельный учебный черновик; production/user data не использовались.

1. Реальное извлечение создало ревизию 2 с pipeline v3, passes=2, двумя pending statements: payment/asserted от narrator и payment/denied от letter_1. Обе дословные цитаты сохранены.
2. Найдена semantic ошибка: «не оплатил» пересказано как «отказ от оплаты». Через UI исправлены обе формулировки. Ревизия 3 сохранила human/pending statements; исходное предложение модели осталось отдельно.
3. Оба утверждения подтверждены вручную; в rationale явно записаны неизвестные время, место, платный режим и сведения об автомобиле. После checklist сохранена ревизия 5 со статусом reviewed. Это проверка разметки учебного текста, не установление фактов или состава нарушения.
4. Новая правка содержания второго утверждения создала ревизию 6: status=draft, изменённое утверждение pending, весь checklist сброшен. Первое неизменённое утверждение осталось confirmed.
5. В истории открыта ревизия 5: прежние формулировки, confirmed statements и checklist сохранены; поля и кнопки изменения отключены, видна подпись «историческая ревизия, только чтение».

Сохранённые JSON revisions дополнительно прочитаны с диска: статусы и pipeline совпали с UI. Browser ledger: 14/15 вызовов, один screenshot, около трёх минут взаимодействия. Снимок остался локальным и не включён в репозиторий.

## Автоматические проверки и границы

- `npm run check`, `npm run lint`, `npm run format:check` — passed.
- `npx tsx --test tests/parking-review.test.ts` — passed. Тест покрывает отдельное сохранение перед подтверждением, сброс после изменения speaker, immutable history, запрет устаревшей записи, неверной цитаты и удаления audit statement; новая фабула начинает пустую цепочку.
- Добавление выделенного текста, отказ модели, экспорт и мобильный layout в этом browser проходе не проверялись. Ошибка модели в браузере не была искусственно вызвана.
- Gaps пока записываются человеком в rationale; отдельный structured gap contract отсутствует. Полнота неизвестных обстоятельств автоматически не доказана.
- Этот экран не выполняет ontology graph assembly, КоАП disposition или Lean calculation. Один walkthrough не измеряет качество модели на корпусе и не доказывает порог 50%.

Следующий ограниченный этап: отдельные structural gap proposals и их ручное подтверждение, чтобы неизвестные обстоятельства были видны отдельным списком, а не только в rationale.
